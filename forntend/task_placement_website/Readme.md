# 🎓 EduTech Learning Portal

A multi-page educational institute website developed using **HTML5** and **CSS3** as part of a Frontend Development assignment.

## 📖 Project Overview

The EduTech Learning Portal is a responsive educational institute website designed to demonstrate the fundamentals of HTML and CSS. The project consists of multiple web pages connected through a navigation menu and showcases various web development concepts such as semantic HTML, Flexbox, CSS Grid, forms, tables, and responsive layouts.
